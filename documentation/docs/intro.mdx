# Capstone Classroom

Capstone Classroom turns a class roster into ready-to-use GitHub project teams. Teachers connect one GitHub organization and share one join link. Students sign in, find their name, and Capstone Classroom handles the team, repository, access, and project site.

:::tip The short version

- **Teachers:** sign in, install the GitHub App, import a Canvas group CSV, and share the join link.
- **Students:** open the link, sign in with GitHub, and select your name.

:::

## What happens automatically

When a student joins a team, Capstone Classroom:

1. Creates or updates the GitHub team.
2. Creates a project repository from the course template.
3. Gives the team access to the repository.
4. Adds the student to the GitHub team.
5. Starts the project documentation site setup.

The page refreshes its status automatically while this work runs.

## Before you begin

| Teachers need | Students need |
| --- | --- |
| A GitHub account that can install apps in the course organization | A GitHub account with an email address |
| A GitHub organization for the class | The permanent classroom join link |
| A Canvas group export CSV, unless teams will be created manually | Their name as it appears on the Canvas roster |

If something does not look right, see [Common questions](./troubleshooting).
