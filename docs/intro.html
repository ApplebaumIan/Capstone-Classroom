Capstone Classroom

Capstone Classroom turns a class roster into ready-to-use GitHub project teams. Teachers connect one GitHub organization and share one join link. Students sign in, find their name, and Capstone Classroom handles the team, repository, access, and project site.

Start Here

Are you a teacher or student?​

  • I am teaching
  • I am a student
TLDR Teachers

Sign in, install the GitHub App, import a Canvas group CSV, and share the join link.

Before you begin you need:

  • A GitHub account that can install apps in the course organization
  • A GitHub organization for the class
  • (Optional) Canvas group export CSV, unless teams will be created manually

Start with the teacher setup guide. Most instructors only need a GitHub organization and a Canvas group export.

TLDR Students

Open the link, sign in with GitHub, and select your name.

Before you begin You need:

  • A GitHub account with an email address
  • The classroom join link provided by your teacher
  • Their name as it appears on the Canvas roster

Open the join link from your instructor, then follow the student guide. You do not need to create a repository or GitHub team yourself.

What happens automatically?​

When a student joins a team, Capstone Classroom:

  1. Creates or updates the GitHub team.
  2. Creates a project repository from the course template.
  3. Gives the team access to the repository.
  4. Adds the student to the GitHub team.
  5. Starts the project documentation site setup.

The page refreshes its status automatically while this work runs.

If something does not look right, see Common questions.
